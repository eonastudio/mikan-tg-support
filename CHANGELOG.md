# Изменения

## 0.1.0 — первая версия

- Аддон протокола 2 для панели mikan ≥ 0.5.1.0: kind `ui`, mode `http`,
  права `ui`, `kv`, `events`. Собственный второй Telegram-бот поддержки
  (токен от @BotFather вводится на странице аддона) — бот-слот панели и
  официальный бот mikan не затрагиваются.
- Тикет-система: тикеты из личных чатов (текст, фото, документы, стикеры),
  один открытый тикет на пользователя, команды `/start`, `/status`, `/close`,
  RU/EN по языку пользователя, антиспам (token bucket), лимит 5000 сообщений
  на тикет, хранение закрытых тикетов с автоочисткой (retention).
- Страница в админке панели: список тикетов (фильтр/поиск/непрочитанные),
  диалог с историей и отправкой ответа, закрытие/переоткрытие/удаление,
  превью фото клиента (data-URL через аддон), настройки (бот, ИИ, хранение)
  с маскировкой секретов и кнопками проверки, страница статуса с обслуживанием
  (ребилд индекса, prune).
- Карточка клиента из событий панели: срок подписки, истечение, трафик 90/100 %,
  последние платежи и возвраты (permission `events`, дедупликация at-least-once).
- ИИ-поддержка (заготовка): OpenAI-совместимый API, режимы off/draft/auto
  (задержка автоответа, «позови человека» отключает ИИ в тикете, sweep после
  перезапуска), персонализация контекста профилем из событий панели и базой
  знаний администратора, защита от prompt-injection, санитизация ответов,
  блокировка cloud-metadata адресов (SSRF), счётчики на странице статуса.
- Надёжность: состояние целиком в KV панели (CAS/if_absent/TTL), идемпотентная
  обработка повторов (update_id, tg_msg_id, event id), skip «отравленных» update,
  backoff'ы на недоступность панели и Telegram, graceful shutdown с сохранением
  offset, `/v2/info` не зависит от состояния.
- Тесты: юнит и интеграция на фейках Panel API / Bot API / LLM (~50 сценариев),
  включая конкурентные CAS-записи и проверки безопасности (401-покрытие,
  маскировка секретов, traversal, валидация RPC, redaction токенов в ошибках).
- Документация: README, INSTALL (три способа установки), BOT (пользователи и
  агенты), AI (настройка и приватность), ARCHITECTURE, SECURITY (модель угроз).
