# tg-support — бот технической поддержки (тикеты) для панели mikan

Аддон протокола 2 для VPN-панели [mikan](https://github.com/Miroshka000/mikan):
**второй** Telegram-бот технической поддержки с полноценной тикет-системой в админке
панели и заготовкой под ИИ-ответы с персонализацией по данным панели.

```
Пользователь ── пишет ──▶ @your_support_bot (собственный бот аддона)
                                   │  тикет создаётся/продолжается
                                   ▼
                        ┌─────────────────────┐      Panel API (kv, events, ui)
                        │  аддон tg-support   │◀────────────────────────────▶ панель mikan
                        │  (контейнер рядом)  │
                        └─────────────────────┘
                                   ▲
Админ/агент ── админка панели ──▶ страница «Тикеты поддержки» ── ответ ──▶ бот ──▶ пользователь
```

## Что умеет

- **Тикеты из Telegram.** Пользователь пишет своему боту поддержки — в панели появляется
  тикет. Агент отвечает на странице аддона — ответ улетает пользователю в тот же чат.
  Текст, фото (с просмотром в админке), документы, стикеры.
- **Команды бота**: `/start`, `/status` (мои тикеты), `/close` (закрыть свой тикет).
  Два языка (RU/EN) — по языку Telegram пользователя.
- **Страница в админке панели**: список тикетов с фильтром/поиском и счётчиком непрочитанных,
  диалог с историей, карточка клиента, настройки, статус здоровья.
- **Карточка клиента из данных панели** (permission `events`): срок подписки, «подписка
  истекает/истекла», трафик 90/100 %, последние платежи с возвратами — то, что панель
  рассказывает в своём фиде событий.
- **ИИ-поддержка (заготовка, уже рабочая)**: любой OpenAI-совместимый API
  (OpenAI, OpenRouter, Groq, vLLM, Ollama, llama.cpp…). Три режима:
  `off`, `draft` (черновик ответа для агента одной кнопкой) и `auto`
  (ИИ сам отвечает, если агент молчал N секунд; слово «оператор» навсегда отключает
  ИИ в тикете). Контекст ИИ — база знаний администратора + профиль клиента из событий
  панели + история тикета. Промпт защищён от injection, ответы санитизируются.
- **Всё состояние — в KV панели** (permission `kv`): тикеты, сообщения, профили и настройки
  живут в базе панели и попадают в её бэкапы. Контейнер не пишет файлов.
- **Не конфликтует с официальным ботом mikan**: слот `bot` панели остаётся у официального
  бота; этот аддон приводит собственного бота со своим токеном и не просит permission `bot`.

## Требования

- Панель и хост mikan **0.5.1.0** (или новее, включая `-rc`) — первые версии с протоколом 2
  аддонов. На стабильных 0.4.x/0.5.0.x аддоны-инструменты не поддерживаются.
- Второй бот, созданный у [@BotFather](https://t.me/BotFather) (его токен вставляется
  в настройках аддона).
- Для ИИ-режимов — API-ключ любого OpenAI-совместимого сервиса (необязательно).

## Быстрый старт

1. Соберите и опубликуйте образ (или загрузите его на сервер архивом — см. INSTALL):

   ```sh
   docker buildx build --platform linux/amd64 --build-arg VERSION=0.1.0 \
     -t <ваш-реестр>/mikan-tg-support:0.1.0 --push .
   docker buildx imagetools inspect <ваш-реестр>/mikan-tg-support:0.1.0  # → digest sha256:…
   ```

2. В админке панели: **Аддоны → Маркетплейс → свой аддон** (или `POST /api/v1/marketplace/custom`):
   - id: **`tg-support`** (ровно этот — хост сверяет его с `/v2/info`),
   - source: `custom`, image: `<ваш-реестр>/mikan-tg-support`, digest: `sha256:…`,
   - kind: `ui`, mode: `http`, permissions: **`ui`, `kv`, `events`**, память: 128 МБ,
   - подтвердите доверие к коду.

3. Откройте страницу аддона в админке → **Настройки** → вставьте токен бота от @BotFather →
   **Проверить бота** → **Сохранить**. Бот начнёт поллить сразу, перезапуск не нужен.

Подробности всех способов установки (реестр, офлайн-архив, внешний процесс без Docker) —
в [docs/INSTALL.md](docs/INSTALL.md).

## Разработка

Go 1.27, только стандартная библиотека (как у официального маркетплейса mikan).

```sh
gofmt -l . && go vet ./... && go test ./...
docker buildx build --platform linux/amd64 -f Dockerfile -t tg-support:dev --load .
# Локальный прогон (панель-заглушка не нужна — аддон переживёт её недоступность):
MIKAN_ADAPTER_LISTEN=127.0.0.1:41999 MIKAN_ADAPTER_TOKEN=t \
MIKAN_PANEL_URL=http://127.0.0.1:41990/panel/v2 MIKAN_PANEL_TOKEN=p ./tg-support
```

Каталоги: `internal/panelapi` (клиент Panel API), `internal/store` (домен на KV),
`internal/telegram` (Bot API), `internal/tickets` (движок), `internal/bot` (поллер),
`internal/evfeed` (события панели), `internal/ai` (LLM), `internal/srv` (HTTP/RPC),
`internal/cfgw` (кэш конфига), `internal/netguard` (SSRF-защита), `web/` (страница аддона),
`internal/paneltest` (фейк панели для тестов).
