# Бот и страница поддержки

## Пользователям (клиентам сервиса)

Клиент пишет **второму** боту сервиса — боту поддержки (не основному боту mikan,
где подписка и оплаты; основной продолжает работать как раньше).

### Как это выглядит

1. Клиент открывает чат с ботом поддержки и описывает проблему обычным сообщением.
2. Бот подтверждает: «🎫 Тикет #N создан. Команда поддержки ответит здесь же.»
3. Ответ агента (или ИИ, если сервис это включил) приходит в тот же чат сообщением
   от бота.
4. Пока тикет открыт, каждое следующее сообщение попадает в тот же тикет — заново
   описывать проблему не нужно.
5. Вопрос решён — клиент закрывает тикет командой `/close` (или это делает поддержка).
   Следующее сообщение откроет новый тикет.

### Команды

| Команда | Действие |
|---|---|
| `/start`, `/help` | приветствие; подсказка, если есть открытый тикет |
| `/status` | мой открытый тикет: номер, статус, число сообщений |
| `/close` | закрыть мой открытый тикет |

### Что можно отправлять

- **Текст** — до 4096 символов (длиннее — отрежется).
- **Фото** — попадёт в тикет, агент увидит снимок прямо в админке (превью до ~700 КБ).
- **Документ** — в тикете будет карточка файла (имя, размер, тип); содержимое агенты
  запрашивают отдельно, если нужно.
- **Стикеры** — принимаются как пометка.
- Аудио/видео/голосовые пока не переносятся — бот вежливо попросит текст или фото.

Правила поведения бота: только личные чаты (в группах бот молчит), не более ~20 МБ
на файл, антиспам-ограничение (4 сообщения сразу, дальше не чаще одного в 2 секунды;
бот предупредит один раз).

### Язык

Бот отвечает на русском или английском — по языку интерфейса Telegram клиента.
Приветствие администратор может задать своим текстом (Настройки аддона → «Приветствие»).

### «Позовите человека»

Слова «оператор», «человек», «позовите», «human», «operator» (и т.п.) в сообщении
помечают тикет: с этого момента ИИ в нём не отвечает — только живой агент.

## Агентам и администраторам (страница в админке)

Страница аддона открывается в админке mikan: **Аддоны → tg-support → страница**
(права `ui`). Это песочница панели: у страницы нет доступа к API админки, все вызовы
идут через сам аддон; каждое действие, меняющее данные, панель пишет в свой журнал
аудита (метод и путь, без тел).

### Вкладка «Тикеты»

- Фильтр: **Открытые / Закрытые / Все**; поиск по тексту заголовка, @username, имени
  или tg id. Обновление списка каждые 10 с.
- В строке тикета: номер, тема (первое сообщение), кто написал, статус, счётчик
  непрочитанных (+N), метка «ИИ», если последним ответил ИИ, время последней активности.

### Диалог тикета

- История сообщений: пользователь — слева, поддержка — справа (зелёные), ИИ — справа
  (фиолетовые, с моделью и временем генерации), служебные — по центру. Обновление
  каждые 5 с, пока диалог открыт.
- **Карточка клиента справа** (данные из событий панели): до какого числа действует
  подписка, «истекает через 3 дня / истекла», трафик 90/100 % текущего периода,
  последние платежи (с пометкой возврата), user id в панели. Пустая карточка —
  пользователь не связан с панелью или событий ещё не было.
- Поле ответа: **Enter** — отправить, Shift+Enter — перенос строки. Ответ мгновенно
  уходит клиенту в Telegram; ответ в закрытый тикет автоматически его открывает.
- Кнопки: **Закрыть**, **Открыть снова**, **Удалить** (безвозвратно, с подтверждением),
  **✦ AI** — черновик ответа ИИ в поле ввода (можно править), **✦ Отправить ИИ** —
  отправить ответ ИИ клиенту сразу.
- Фото клиента открываются кликом (превью); файлы крупнее лимита показываются карточкой.
- Открытие диалога сбрасывает счётчик непрочитанных.

### Вкладка «Настройки»

| Настройка | Смысл |
|---|---|
| Токен бота | токен второго бота от @BotFather; хранится в KV панели, в интерфейсе не показывается (только факт «задан»). Пусто при сохранении — оставить прежний |
| API Telegram | если Bot API с сервера не виден — адрес зеркала/прокси (по умолчанию `https://api.telegram.org`) |
| Приветствие | текст `/start` (пусто — встроенный RU/EN) |
| ИИ | см. [AI.md](AI.md) |
| Хранить закрытые тикеты, дней | срок, после которого закрытые тикеты стираются из KV (открытые не стираются никогда); по умолчанию 60 |

Кнопки **Проверить бота** (getMe без сохранения) и **Удалить токен/ключ** (стирание
секрета из KV).

### Вкладка «Статус»

Здоровье всех частей: бот (поллинг, @username, offset, ошибка), события панели
(права, сколько применено), ИИ (сколько авто-ответов/черновиков, ошибки), панель
(id, версия, одобренные права), KV (число тикетов и профилей). Кнопки обслуживания:
**Перестроить индекс** (ремонт списка тикетов из хранилища) и **Очистить старые
закрытые** (немедленный prune по сроку хранения).

### Рекомендации по процессу

- Один тикет = один клиент (личный чат). Несколько агентов могут отвечать в один
  тикет; история общая, но страница не различает, какой админ ответил (панель
  передаёт аддону только язык интерфейса) — ответы помечаются просто «поддержка».
- Следите за счётчиком непрочитанных в списке — это очередь.
- Если ИИ включён в режиме `auto`, живые ответы агентов всегда приоритетнее:
  ИИ отвечает только если агент молчал дольше задержки, и мгновенно замолкает,
  как только агент ответил или клиент позвал человека.
